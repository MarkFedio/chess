# chess
Chess made with Pygame. No AI (including the pieces which I drew in MS Paint...)

Run using
python main.py {0 or 1}
  0 will make the board flip after each turn
  1 will make the board keep its orientation


This source code is for what's hosted on my site. It does not have an engine implementation because that relies on multiple threads, which pygbag does not support. When I have finished my engine, that version's code will be here.
